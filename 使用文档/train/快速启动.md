# 快速启动 - 命令速览

> 适用环境：`verl_train_2`（WebShop/Search/Retriever 共用集成环境（包括train+eval），由 `install_verl_train.sh` 创建，已集成数据准备脚本，可取代官方环境安装，避免代理和pack版本等各种问题）
> 命令默认在项目根目录 `/diskpool/home/xuxz/Code-for-DPEPO` 下执行，训练脚本中项目路径靠脚本中两个变量控制，.py中会同步读取两个环境变量
> 详细说明见 `使用文档/train/完整说明.md`

## 1. 环境安装

```bash
# 一键安装 verl_train_2 环境（Python 3.11 + PyTorch + vLLM + Ray + verl，共 12 步，自动验证）
# 也可使用official_scripts.sh安装 使用官方的安装脚本 跳过chapter1-2
bash train_scrips/install/install_verl_train.sh

# 安装 spacy 模型（需要代理，可选）
conda activate verl_train_2
pip install "en_core_web_sm @ https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.8.0/en_core_web_sm-3.8.0-py3-none-any.whl"
```

## 2. 数据集下载与检索索引

> ⚠️ `setup_data_verl_train.sh` 头部手动设置了 `HOME_DIR`（用户目录）与 `PROJECT_NAME`（项目名），换机器或调整目录结构时，需先修改这两处再执行。

```bash
# 一键完成全部数据准备（WebShop 下载+商品索引、Search 预处理+检索索引；幂等，已存在自动跳过）
bash train_scrips/install/setup_data_verl_train.sh

# 可选：按需分别准备
bash train_scrips/install/setup_data_verl_train.sh webshop   # 仅 WebShop
bash train_scrips/install/setup_data_verl_train.sh search    # 仅 Search
```

## 3. 模型下载

### 3.1 SFT Checkpoint（Qwen2.5-1.5B-Instruct 冷启动，ModelScope）

> 使用一键脚本 `train_scrips/install/download_sft_ckpt.sh` 下载（需在 `verl_train_2` 环境下执行）。脚本仅下载 2 个推荐 checkpoint（Search 10500 + WebShop 8800），各 checkpoint 验证结果见 `使用文档/train/完整说明.md` 1.5.1 节。
>
> **自定义变量**（脚本头部，换用户/机器时只需改这里）：
> - `LOCAL_CKPT_DIR`：下载根目录（默认 `/diskpool/home/xuxz/test_download`），两个 checkpoint 分别下载到其下 `search_3.5epoch_10500it`、`webshop_5epoch_8800it` 子目录
>
> ⚠️ 模型放置位置一旦改变，必须同步修改训练脚本中的 `actor_rollout_ref.model.path`。

```bash
# 方式一：一键脚本下载（下载到 $LOCAL_CKPT_DIR 下的两个子目录）
pip install modelscope   # 首次使用需安装
bash train_scrips/install/download_sft_ckpt.sh

# 方式二：Git 完整克隆（含全部 4 个 checkpoint）
git clone https://www.modelscope.cn/afordb/sft_result_webshop_and_search_based_on_qwen.git
```

> 训练脚本默认模型路径：
> - Search：`/diskpool/home/xuxz/ms-swift/checkpoint_search/Qwen2.5-1.5B-Instruct-Parallel-Epoch5-hislen8_seed1_1000sample/v1-20260715-204318/checkpoint-10500`
> - WebShop：`/diskpool/home/xuxz/ms-swift/checkpoint/Qwen2.5-1.5B-Instruct-Parallel-Epoch5-hislen8/v0-20260602-201729/checkpoint-8800`
> - 模型放其他目录时，需修改训练脚本中的 `actor_rollout_ref.model.path`

### 3.2 BGE 嵌入模型（多样性惩罚必需）

> ⚠️ 默认下载到项目内相对路径 `emb_models/bge-large-en-v1.5`；若改为其他目录，需同步修改训练脚本中的嵌入模型加载路径。

```bash
# 方式一：HuggingFace（国内超时可先 export HF_ENDPOINT=https://hf-mirror.com）
hf download BAAI/bge-large-en-v1.5 --local-dir emb_models/bge-large-en-v1.5

# 方式二：ModelScope
modelscope download --model BAAI/bge-large-en-v1.5 --local_dir emb_models/bge-large-en-v1.5
```

> ⚠️ 训练时 `local_files_only=True`，模型缺失会直接报错，务必提前下载。

## 5. 启动训练

### 5.1 激活环境

```bash
conda activate verl_train_2
cd /diskpool/home/xuxz/Code-for-DPEPO
```

> ⚠️ `cd` 的绝对路径需与项目实际位置一致；若项目不在 `/diskpool/home/xuxz/Code-for-DPEPO`，请改为实际路径。

### 5.2（仅 Search 任务）启动检索服务器

```bash
bash examples/search/retriever/retrieval_launch_faiss.sh
curl "http://127.0.0.1:8010/retrieve"
bash 使用文档/test_retriever.sh   # 一键测试检索服务器是否就绪（Search）
```

> 训练脚本通过 `SEARCH_PORT=8010` 连接（与启动脚本内 `PORT=8010` 一致）；端口被占用时需同时修改两处。

### 5.3 启动训练

> ⚠️ 执行前必须修改训练脚本头部的路径变量：
> - `DPEPO_USER_HOME`：用户目录（默认 `/diskpool/home/xuxz`）
> - `DPEPO_PROJECT_NAME`：项目目录名（默认 `Code-for-DPEPO`，与 `DPEPO_USER_HOME` 共同派生 `_CODE_BASE` 等项目路径）
> - `actor_rollout_ref.model.path`：SFT 基座模型路径（Search/WebShop 各不相同）
> - `ckpt_dir`：训练输出目录（默认 `3emb_model_bs4_search/search_emb_0.8_bs4` 等）
> - `CUDA_VISIBLE_DEVICES`：GPU 编号（按实际可用 GPU 修改）

```bash
bash train_scrips/for_search/train_similarity_bs4/eval_emb_0.8.sh      # Search emb 0.8（双卡）
bash train_scrips/for_search/train_similarity_bs4/eval_no_emb_1.sh     # Search no_emb（双卡）
bash train_scrips/for_webshop/train_similarity_bs4/eval_emb_0.8.sh     # WebShop emb 0.8（双卡）
```

### 5.4 监控日志

```bash
# 日志在 ckpt_dir/log/，脚本自动 tail -F
tail -F <日志路径>   # 替换为脚本打印的实际日志路径
```

### 5.5 停止训练

```bash
kill <PID>                              # 脚本启动时会打印 PID
ps aux | grep main_ppo_search           # 或按进程名查找
```

### 5.6 合并 LoRA 权重（训练完成后）

> ⚠️ 合并前必须修改 `merge_lora_noemb.sh` 中的路径：
> - `BASE_MODEL`：SFT 基座模型路径（需与训练脚本 `actor_rollout_ref.model.path` 一致）
> - `ckpt_path`：训练产出的 checkpoint 目录（如 `3emb_model_bs4_search/search_emb_0.8_bs4/global_step_125`）
>
> 合并产物输出到 `$ckpt_path/merged`。

```bash
bash train_scrips/merge_lora/merge_lora_noemb.sh
# 若 ms_swift 环境缺失，先安装：
conda create -n ms_swift python=3.11 -y
conda activate ms_swift
pip install ms-swift
```
