### 3.2 词序重排 #41 的新问题

| | 原始 sim | 放大后 | 判定 |
|---|:--:|:--:|:--:|
| base | 0.987 (>0.975) | 0.499 | ✅ OK (期望 True) |
| → 放大后 | 0.987 | **0.000** | ❌ XX (放大前 > 0 但现在 < 0? 不对) |

> **等一下**: #41 在 base 中 XX 是因为放大后 **0.0000**？这说明词序重排的原始 sim 0.987 在范围放大后 = (0.987 - 0.975)/(1 - 0.975) = 0.48，应该 > 0 才对。
> 但日志显示 base #41 = 0.0000，说明**词集匹配没有命中**，且**嵌入 sim < 0.975**（原始 sim 可能因为保留大小写导致变化）。

### 3.3 保留大小写对 search 路径的影响

当前代码在 search 路径**保留了原始大小写**（仅 click 转小写）。这意味着：

- `search[Van Heusen ...]` vs `search[van heusen ...]` 的精确匹配会失败（`Van` ≠ `van`）
- 词集匹配也会失败（`{Van}` ≠ `{van}`）
- 只有嵌入兜底能处理，但嵌入用原始大小写文本

**这就是 #41 在 base 中 XX 的原因**：保留大小写后，`Van Heusen` 和 `van heusen` 的词集不同，精确匹配失败，嵌入 sim 0.987 > 0.975 被放大为 0.48 > 0，应该 OK... 但日志显示 0.0000。

> 实际原因：#41 的两个动作是 `search[Van Heusen men's ... stretch]` vs `search[van heusen men's ... stretch]`，保留大小写后**词集不同**（`Van` vs `van`），走嵌入兜底，但原始 sim 可能因为大小写差异降到了 < 0.975。

### 6.1 范围放大的效果

| 指标 | 放大前 (201549) | 放大后 (022046) | 变化 |

> **范围放大不影响正确率**，因为 `sim > 0.0` 的判定与放大前的 `sim > 0.0` 等价（放大只是线性变换，0 还是 0，正数还是正数）。

## 七、改进建议

### 7.1 ⚠️ 恢复 search 路径的统一转小写

**问题**: 当前代码在 search 路径保留了原始大小写，导致：
- `Van Heusen` vs `van heusen` 的精确匹配和词集匹配都失败
- 嵌入模型对大小写不一致的文本给出更低的相似度

**修复**: 在函数入口统一转小写（之前的做法），或在 search 路径提取内容后转小写：

```python
content_a = action_a[7:-1].lower()
content_b = action_b[7:-1].lower()
```

**预期效果**: #41 在 base 中恢复为 OK（词集匹配命中），base 正确率回到 90.8%

### 7.2 范围放大方案评估

**当前**: `sim < threshold -> 0.0`, `[threshold, 1.0] -> [0, 1]` 线性放大

**优点**:
- 相似度值更分散，便于下游加权计算（`α^C` 中的 C 不会被 0.98 的相似度主导）
- 阈值附近的相似度被压缩到 0 附近，减少了"微弱过阈值"的过度惩罚

**缺点**:
- 不影响判定正确率（`> 0` 的判定与原始 `> 0` 等价）
- 误检条目（如 cotton vs polyester）仍然误检，只是分值从 0.98 降到 0.22/0.51

**建议**: 范围放大**适合下游加权计算**，但如果只是做二值判定（重复/不重复），则**不需要放大**，直接用原始 sim > threshold 即可。

### 7.3 同义词表（方案 F）仍是核心改进

当前 15 个共同错误中：
- **5 条** cotton spandex↔stretch：需要 `spandex -> stretch` 映射
- **8 条** 跨类别同义替换：需要 sofa/couch、charger/pad 等同义词表
- **1 条** curtain/curtains 单复数：需要词形归一化
- **1 条** cotton vs polyester 误检：需要关键属性差异拦截

**实施同义词表 + 词形归一化后，预计正确率**:
- base: 90.3% -> **97.4%** (修复 14 条，剩余 5 条 cotton vs polyester 误检仍需方案 G)
- large: 92.3% -> **99.5%** (修复 14 条，剩余 1 条 cotton vs polyester 误检)
