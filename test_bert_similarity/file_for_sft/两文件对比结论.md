# 两文件前10条 messages 对比结论

## 文件信息

- **文件1 (noted)**: `test_bert_similarity/file_for_sft/merged_success_output_new_excluded_first500_final_his8_noted.json`
- **文件2 (sample)**: `test_bert_similarity/file_for_sft/merged_success_output_new_excluded_first500_final_sample_his8.json`

## 基本结构

- 两个文件均为 **3520 条记录**的 JSON 数组
- 每条记录结构为 `{"messages": [...]}`，每条 message 包含 **3 条消息**（system / user / assistant）

## 唯一区别

两个文件的**唯一差异**在于 user message（index 1）中的提示词文本：

| | `noted` 文件 | `sample` 文件 |
|---|---|---|
| **提示词** | `Below are the most recent 8 observations and the corresponding actions you took:` | `Below are the most recent observations and the corresponding actions you took:` |

即 `noted` 文件在提示词中明确写了 **"recent 8 observations"**（标注了历史窗口大小为 8），而 `sample` 文件只写了 **"recent observations"**（没有标注数字）。这导致 `noted` 文件每条差异记录的 content 长度比 `sample` 文件多 **2 个字符**（即 ` 8`）。

## 统计

- **500 条记录完全相同**（无差异）
- **3020 条记录存在上述差异**，且差异模式完全一致——都是 `the most recent 8 observations` vs `the most recent observations`，除此之外内容完全相同。

## 结论

`noted` 文件是在 `sample` 文件的基础上，将提示词中的 `"the most recent observations"` 改为了 `"the most recent 8 observations"`，**显式标注了历史观察窗口的大小为 8**。其余所有数据内容完全一致。
